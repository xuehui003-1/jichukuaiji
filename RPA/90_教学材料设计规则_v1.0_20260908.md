# 教学材料设计规则 v1.0（2026-09-08）

> 本文件是历轮修改经验的规律化沉淀。**做任何课件/记录册/手册改动前先通读，按此执行，不等用户提醒。**
> 改动本文件的只能是用户的新纠正；每条纠正落地当天必须记入对应小节。

## 一、学情铁律（一切设计的前提）
1. 教学对象＝高职大二专科（会计学院 · 大数据与会计 2501 班）：理论弱、动手强。
2. **创意/组织/策划/设计类活动基本别指望；动手执行类可以**。活动一律「学生只执行」：考题、步骤、模板由课件给定印明，不让学生自己设计考题、自己策划流程（p54 三数互验、p53 全班找错即此形态）。
3. 指令必须明确：每页写清「干什么、写在哪、几分钟、怎样算过关」；禁模糊话术（「对一带」类病句、突兀编号 ⓪）；分步用「第一步/第二步」或「第 1 行/第 2 行」。
4. 生活化铁律：案例贴石家庄/石邮院日常（地铁 2 元、隆兴寺预约号、正定一日游、西门打印店…）。
5. 费曼/反灌输：禁定义先行，先活动后术语；比喻统一「变量＝贴了标签的储物格」，一课一词。
6. 轻活动重案例；答案永远最后出现，问题与答案禁同屏（含抢答/口算/讨论行）。

## 二、课件页规范（HTML SLIDES）
7. **暂停点全册统一编号**：项目二＝①–⑲（08=①–⑭、10=⑮–⑲ 续号），编号＋标题随页展示，右上角 📒 徽章同步同号；任何抽查页必须写明来源（哪个暂停点/记录册哪页/哪次课后任务），禁「上一页」类相对指称。
8. **进度指称全面禁用**：第N次课/第X讲/下节课/上次课/册子X/追加页——改功能性说法（进机房揭晓/接下来/收尾布置的课后任务）。校验正则注意「第3讲义」是误报。
9. **双面打印约束**：禁「任务卡背面」「写在背面」类语句——记录册打印是双面的，背面有内容；一切书写落点＝记录册对应暂停点页。
10. 任务难度的分流方式：难度基本相当才可二选一；难度不等一律「先 A 后 B」（A 全班必做 → B 加时赛）。
11. 课堂活动只做动手执行型：抢答、动笔、对照揭晓、换数互考、找错；**禁角色扮演**（人肉机器人/主管/口令/举手线）、禁互审打分、禁自制道具。复杂活动规则必须简单可执行（固定步骤＋固定时间）。
12. **大任务节奏**：每项目/每章收尾放 1 个长周期（约一周）综合任务，不做进每个知识点之后；记录册设「大任务」登记页。大任务五条硬标准：①**校内可完成**——禁依赖家人配合（学生住校，没人真打电话）；②照课上已练的模板做（有样可抄）；③步骤逐条给定（①②③④，每步一句话）；④检查方式写明——收记录册对格子或课堂当场跑/投屏；⑤完成标准一句话说死（例：流水 7 行＋当场跑通＝满分）。
13. 版面：大字号可放大、全屏无黑边；暂停页（.pause 深红底）上禁用深绿字——红底文字用 #FFE082 琥珀或白；浅底页绿字仅限 .stu/.anscard。
14. 插图：一律 AI 绘图（generate→read_file QC→image-edit 修→植入→node 校验）；提示词 v2.0 五要素＋人物设定表（小邮=橙色小邮差机器人）；图内文字逐字写死，乱码/自造内容/假代码拒植；点图放大灯箱：**灯箱开着时点击/按键只关灯箱**（capture 监听首行 `if (lb.style.display!=="none") return;`，新课件照抄此引擎）。
15. 「还有N条未揭晓」提示条数＝该页真实可揭晓数，随翻页刷新（resetRv 在 cur 更新之后调用，勿动时序）。
16. 每次改动后必跑 node 校验：页数、无空页、暂停点首现页严格递增、残留正则、图片 src 全存在。

## 三、学生记录册规范（05）
17. 定位＝**学生记录内容＋老师检查的工具**，只保留四类内容：(a) 暂停点格 (b) 填写表格 (c) 老师布置的任务 (d) 每章一行下课前自查。其余话术越少越好。
18. 每个暂停点格必须标注：**编号＋标题＋课件页码**，格式「⏸ 暂停点⑫ · 图纸三行　——课件 08 · p51」；页码与课件一一对应，课件改页后同一轮更新册子。
19. 禁出现：第N次课/第N讲/教室课/机房课/人肉运行/三板斧/没图纸不开工/册子X/追加页。
20. 老师布置的任务逐条写进册子（每课件收尾一页：必做/选做＋来源课件页码＋记在哪）。
21. 五类＝**数值/字符/日期/时间/文件**（④地铁票价 2 元是「常量」彩蛋，不是类别名）；十二货清单以课件 08 p15 为准。
22. **课件活动重造时，册子对应格必须同一轮重做**（教训：课件⑬⑭换成找错/互验后，册子还是「人肉记录四行/主管验收单」）。

## 四、教师答案对照手册规范（12）
23. 由 `_refs/gen_manual_12.py` 从课件 SLIDES **自动提取**生成，页码零手抄（v1.1 手抄 off-by-one 教训）；课件改动后重跑，版本号 +1，删旧版。
24. 六列：页／页面／学生干什么／老师怎么讲／答案类型·参考答案／常见卡点·应对。答案类型三标：【固定答案】【开放·言之有理即可】【有参考答案】。

## 五、工程流程
25. 每轮开头：`git status`＋`git log --oneline -1` 对照远端，落后即 `git pull --ff-only`；成果尽早 commit（沙盒会重置，未提交＝会丢）。
26. 交付流程：改课件 → node 校验 → 重生 12 手册 → 记录册同步 → commit → push → present → 汇报（含暂停点/页码变动总表）。
27. git：能普通 push 不 force；`_refs/` 被 ignore，入库用 `git add -f`；入库后 `git ls-tree` 双验。
28. 文档只留最新版＋版本号，旧版删除。
30. **「没带作业」兜底铁律**：凡课堂依赖上次课后任务（图纸/流水/判断）的页，必须同页给「备用素材」——①4 套以上参数各异的现成场景卡（难度相当、生活场景、每人抽一张不同卡，防互抄）②参数印死在课件/卡上（学生不用自己编数）③走备用通道照样全流程、照样给分——课堂不等作业，作业债课后补。
31. **手册 CC 讲法列必须含兜底**：凡该页依赖学生自带材料，CC 列写明「没带的怎么办」（抽备用卡/共用/照示例抄），规划文档对账节同步。
33. **任务指令三要素铁律**：任何让学生动手的任务（课后/选做/大任务/互审/互判/互验），必须写全——①第一步做什么（谁念谁跑、念什么跑什么，动作给到位）②交付物（写在记录册哪一页、什么格式）③完成标准（怎么算对、怎么给分）。禁「给图纸加一条新规矩」式半句话任务——规则≠任务。专科生的时间要花在执行上，不花在猜题意上。
34. **课后选做素材必须校内实地存在**：取材范围＝食堂套餐价／打印店单双面价／小卖部单瓶整箱价／澡堂打水机。校内没有「满X减Y」「第二件半价」招牌——禁再布置找招牌；「二选一价目」处处都有。
35. 脚本坑位备忘：**SLIDES 解析一律走 node 权威提取**（`_refs/extract_slides.js` → JSON），禁止 python 文本 split（已踩坑：`{cls:` 头被 join 吞掉→浏览器白屏；模板里假 `];` 截短 body；`},\n,{` 双逗号产生稀疏洞→空白页）；替换锚必须含内联标签原样（先 repr 再写）；相同的 eyebrow 文案多处出现时按页 chunks 索引定位替换，别全局 replace。
