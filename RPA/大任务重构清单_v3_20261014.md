## 一、各任务详单

### 讲4 · 大任务：运动会成绩播报员（10 册改造）

**场景**：下周校运会，班里的成绩要当场播报。今天把"播报员"拼出来：录入 3 名运动员的成绩，算出总分播报，总分够 20 分弹"班级加分 +2"。

**任务卡**：在哪——机房一人一机｜干什么——把成绩播报员拼出来跑通｜做到什么程度——先猜后跑、弹出的总分和加分提示都对、翻车自己修｜交什么——chengJiBoBaoJSQ-学号 上架＋记录册任务单。

**流程（一步一动）**：
1. 热身跑《打招呼》：先猜输出→真跑→对照三件事（10 分钟，机器人开口了才能干活）；
2. 纸上先走：播报流程画成图纸三行（三名成绩格→总分=三人相加→弹总分；判断行：总分≥20 → 弹"班级加分"）；
3. 先猜：照图纸把"会弹什么"写进记录册猜想格（猜错不扣分）；
4. 动手拼：变量块建成绩格→输入块录成绩→运算块求和→弹窗播报→**如果块**判加分（顺序：录入→计算→播报→判断）；
5. 真跑：跑 15+18+12=45 → 弹 45 分＋"班级加分"两连弹；跑 5+4+6=15 → 只弹 15 不加分——两种结果都要验到；
6. 翻车检修：老师投屏一个真报错（文本当数加），全班抄三个词→排错三行→改到跑通；
7. 上架＋互考：保存 chengJiBoBaoJSQ-学号；同桌互换换三个数再跑一轮。

**思考过程**：机器人凭什么播报？——成绩得先有地方放（变量格）→ 放进去按什么顺序处理？——录入→相加→播报→判断，一步乱全盘乱 → 够不够 20 分谁来定？——如果块，条件写反就"不及格也加分" → 弹错了先读报错，别喊老师。

**旧内容去向**：打招呼（旧⑮）→工序1 热身；余额格（旧⑯）→**保留为备选降级任务**（播报器拼不动的学生改拼余额格，同样先猜后跑，照样给分）；读报错（旧⑰）、排错三行（旧⑱）→工序6。

### 讲5 · 大任务：外卖计算器搬上机（14 册改造）

**场景**：⑫ 那节全班画好了外卖满减计算器的图纸（39.9 元/份 × 份数，满 25 减 4）。今天图纸变真程序——校门口外卖店真在用这个价。

**任务卡**：在哪——机房｜干什么——照⑫的图纸把外卖计算器拼出来上架｜做到什么程度——2 份弹 75.8、1 份弹 39.9（不满 25 不减）、卡住按调试三步自救｜交什么——waimaiJSQ-学号 上架。

**流程**：1. 掏出⑫的图纸对齐三行（变量/命令/串法）→ 2. 看老师搬家演示（拖/摆/连各 10 秒，输入块永远在最前）→ 3. 全员照图纸拼（只问"对图纸了吗"，不代改）→ 4. 先猜 115.7 写猜想格→真跑→2 份弹 75.8 全班喊出来→1 份验证"不满 25 原价"→ 5. 卡住按调试三步（读→定位→一次只改一处），两分钟救不回再举手 → 6. 保存 waimaiJSQ-学号 登记"已上架"→ 7. 备用卡通道（没带图纸的照卡拼，照样给分）。

**思考过程**：图纸上每一行=软件里哪块？——对号入座，不即兴 → 为什么输入块在最前？——没数进来后面全白算 → 75.8 是验证出来的，不是碰出来的 → 改错只改一处，改两处就不知道是哪改好的。

**旧内容去向**：一句话流程（旧⑳）、搬家三步（旧㉑）、排错三行（旧㉒）、三句话（旧㉓）→全部收编为工序。

### 讲6 · 大任务：校运会项目流水录入机（16 册改造）

**场景**：校运会有 30 个项目，每个项目成绩出来都要录一遍、播一遍——手拖 120 块积木会断手。今天给录入机装上循环，填"项目数"让它自己转。

**任务卡**：在哪——机房｜干什么——把播报器升级成流水录入机｜做到什么程度——次数填几转几圈、每圈弹"第 N 项：xx 分"、300 翻车能按停救回｜交什么——xunHuanJSQ-学号 上架。

**流程**：1. 全班喊"30 个项目拖几块"（120 块，手会断）→ 2. 看循环块演示（成绩录入+播报装进肚子，次数框填项目数）→ 3. 全员装好：先填 3 跑通（弹 3 轮，每轮都是"录→弹"）→ 4. 接输入框：先猜"答 30 转几圈"再跑 → 5. 救援演练：次数改 300 翻车→按停→改回→排错三行 → 6. 上架 xunHuanJSQ-学号→ 7. 备用卡通道（四套参数印死，一人一张，照样给分）。

**思考过程**：哪段在重复？——"录一项弹一项"装肚子 → 次数=项目数，改次数不改肚子里的积木 → 300 圈=广播喊 300 遍（安全规矩：跑之前先想它停不停）。

**旧内容去向**：备用卡（旧㉔）、循环动手（旧㉕）、300 翻车（旧㉖）、三句话（旧㉗）→收编为工序。

### 讲7 · 大任务：班费罐提醒器（17 册改造）

**场景**：班里想买饮水机（500 元），班费每月 +200。今天做个提醒器：每月转一圈，攒满 500 自己喊"该买饮水机了"——你不用盯着，它自己会停。

**任务卡**：在哪——机房｜干什么——给班费罐装上"自己会停"的判断｜做到什么程度——先猜圈数圈圈对、死循环能按停、弹"该买饮水机了"时机对｜交什么——cunQiGuan-学号 上架＋**项目收尾大任务四步草稿**（真实数据、五条硬标准、同桌验收签字）。

**流程**：1. 抢答旧录入机的毛病（次数填死：项目改了它不改）→ 2. 口诀"没到就继续，到了就停"——判断装进循环肚子（每月+200→判断够没够 500）→ 3. 先猜 0→500 转几圈（正字记圈）→ 4. 全员 12 分钟拼跑：输入 200 验证 3 圈停 → 5. 救援：判断块掉肚子外=死循环，按停→拖回→排错三行 → 6. 上架 cunQiGuan-学号 → 7. **项目收尾大任务当堂起草**：从七讲七件上架作品里挑一条线，用真实数据做自己的作品（四步：定场景→画图纸→拼跑→同桌验收签字）。

**思考过程**：判断=停车线，管的是"转不转下一圈" → 条件写反=永远停不下或一圈就停 → 跑之前先想怎么停 → 大任务=把七讲的操作串成一件自己的作品。

**旧内容去向**：备用卡（旧㉘）、记圈数（旧㉙）、真机四步（旧㉚）、三句话（旧㉛）→收编为工序。
