## 一、流程与思考过程（与 v3 相同，数据按上表）

### 讲4 · 运动会成绩播报员（10 册改造；旧⑮–⑱收编为工序）
**流程**：①热身跑《打招呼》（先猜输出→真跑→三件事对照）→ ②画图纸：名次格→换积分→求和→够线弹榜 → ③先猜两种名次组合的结果写猜想格 → ④动手拼：变量块×3→输入块→如果块换积分（1→5/2→3/3→1）→运算块求和→如果块判上榜→弹窗 → ⑤真跑两组验证数 → ⑥翻车检修（文本当数加的真报错：抄三个词→排错三行→改通）→ ⑦上架＋同桌换名次互考。
**思考过程**：成绩放哪（变量格）→ 名次怎么变积分（条件选路：第几名走哪条）→ 加的顺序对不对（先换算再相加，顺序乱结果就错）→ 够不够10分谁说了算（如果块）→ 弹错了先读报错。
**备用通道**：没做准备的学生领备用卡（卡上印死三组名次与答案），照卡先猜再跑，验过照样给分。

### 讲5 · 外卖计算器搬上机（14 册改造；关口⑰）
**流程**：①掏⑫图纸对齐三行 → ②看搬家演示（拖/摆/连各10秒）→ ③照图纸拼 → ④先猜 2份/3份 各弹多少→真跑→75.8/115.7 全班喊出来→1份验"不满25原价" → ⑤卡住按调试三步自诊两分钟 → ⑥保存 waimaiJSQ-学号 上架 → ⑦选做：外卖App查自己常点的店改参数重验（板面13元满20减3→2份23元）。
**思考过程**：图纸行=哪块积木（对号入座不即兴）→ 输入块为何最前 → 得数是验出来的 → 改错一次只改一处。

### 讲6 · 校运会项目流水录入机（16 册改造；关口⑱）
**流程**：①喊痛点"30 个项目拖几块"（120块）→ ②循环块演示（录入+播报装肚子、次数填项目数）→ ③先填3跑通 → ④接输入框，先猜"答30转几圈"再跑 → ⑤数一数今年秩序册项目数，填真数跑 → ⑥300翻车：按停→改回→排错三行 → ⑦上架 xunHuanJSQ-学号；备用卡（四套参数印死）。
**思考过程**：哪段在重复（装肚子）→ 次数=项目数，改次数不改肚子 → 300圈=广播喊300遍（跑之前先想它停不停）。

### 讲7 · 班费罐提醒器（17 册改造；关口⑲）
**流程**：①抢答旧录入机毛病（次数填死）→ ②口诀"没到就继续，到了就停"，判断装进循环肚子 → ③先猜每月200转几圈（正字记圈）→ ④全员12分钟拼跑，验证第3圈600≥500停并弹"该买饮水机了" → ⑤换每月100验5圈整（500≥500 恰好卡线）→ ⑥救援：判断掉肚子外=死循环，按停拖回+排错三行 → ⑦上架 cunQianGuan-学号 → ⑧项目收尾大任务当堂起草（七件上架作品里挑一条线，真实数据四步：定场景→画图纸→拼跑→同桌验收签字）。
**思考过程**：判断=停车线，管"转不转下一圈" → 500含不含500（边界）→ 跑之前先想怎么停 → 大任务=七讲操作串成自己的作品。
