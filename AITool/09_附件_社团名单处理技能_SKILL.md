# 社团名单处理技能（SKILL.md）

> 说明：这是 AI 工具课教师自制的教学技能包。在 WorkBuddy 里用「上传技能」导入本文件所在文件夹，启用后在对话中用 / 调用。

## 这个技能是干什么的
把一份写得很乱的社团报名名单，按本校社团联合会的规矩整理成一张标准表，并交出一个可下载的文件。

## 必须遵守的规矩（本校标准）
1. 官方社团名只有五个：篮球社、摄影社、电竞社、志愿者协会、街舞社。学生写错的要自动改正：
   - 「篮球队」「篮球协会」→ 篮球社
   - 「拍照社」「摄影协会」→ 摄影社
   - 「电竞队」「王者荣耀社」→ 电竞社
   - 「志愿队」「青协」→ 志愿者协会
   - 「街舞队」「舞蹈社」→ 街舞社
   改不认出来的名字时，保留原文并在括号里注明「待确认」。
2. 表格列固定为：姓名 / 社团（官方名）/ 报名时间 / 联系方式。
3. 同一社团的人排在一起，社团之间按人数从多到少排。
4. 表末加统计区：每个社团的人数、占总人数百分比（保留一位小数）、合计行。
5. 表格最末加一行：「指导教师签字：＿＿＿＿　日期：＿＿＿＿」。
6. 交付物：一个可下载的文件（.xlsx 或 .csv 均可），同时在对话里贴一份预览表。

## 不许做的事
- 不许编造名单里没有的人。
- 不许删掉「待确认」的行。
- 联系方式缺失就留空，不许补假号码。
