## 二、WorkBuddy 发布（推荐，5 步）

1. 打开 WorkBuddy → **资料库** → 上传 `01_核心作品_*.html`
2. 打开文件预览，确认五个标签页都能点、机器人能跑
3. 右上角 **分享** → 切到「**发布**」页签 → 打开「**发布为网站**」开关
4. 立刻得到 `workbuddy.link` 公开短链——**手机和电脑各打开一遍**验证（对方无需登录 WorkBuddy）
5. 以后改版：改完 HTML 重新上传发布，链接指向最新版

注意：
- 链接即公开。页面已做匿名设计（不出现学生姓名、数据存访问者本机），可放心公开
- 指南要求**链接有效期至少到活动结束后 1 个月**——发布后别下线
- 若平台托管的页面拦截浏览器直连大模型接口（CORS），应用会自动回退「演示模式」，功能不缺，演示不受影响
