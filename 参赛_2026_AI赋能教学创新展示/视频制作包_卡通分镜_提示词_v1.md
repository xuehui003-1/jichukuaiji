## 三、操作步骤（即梦 / 可灵 / Runway 通用）

1. 每个镜头：**上传帧图 → 选"图生视频" → 整段贴角色设定表 + 该帧提示词 → 生成 2–3 秒**；
2. 同一角色的镜头尽量用同一工具同一模型，一次生成不理想就重roll；
3. 剪映合成：按表顺序排列 → 每段之间**叠化 0.5 秒** → 音轨替换为对应 mp3 → 导出 1080p MP4；
4. 成品传到本分支，文件名沿用 `xyintro.mp4 / tmap.mp4 / libtour.mp4`，我来压缩内嵌。
