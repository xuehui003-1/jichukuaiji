**实录帧截法**（中距离实拍说明）：课堂实录是教室中部的单机位——投影能看清但不锐利、学生整体可见、个人小动作不明显，所以**凡是要"看清楚"的内容都用页面截图垫图，实录帧只负责证明"这事真发生在教室里"**。播放两条实录视频，暂停后 Win+Shift+S 截屏保存。D6 记录册：实录拍不到（册子在学生手里），用手机把记录册摊到暂停点⑨那页拍一张即可。
