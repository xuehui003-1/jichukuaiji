# 镜头02：软件整体结构

## 1. 这个镜头到底是什么

这是一个由后期人员制作的 **二维信息图动画**，不是软件录屏，也不是教师在PPT里现场绘图。

制作方式非常简单：

1. 先设计一张完整的结构信息图；
2. 再让信息图中的卡片、文字和箭头按照时间顺序淡入；
3. 不需要制作人物动画，不需要三维动画，也不需要复杂特效。

可以理解为：

> 一张结构图，分四步出现。

## 2. 为什么需要这个镜头

后面的视频会先操作学生端，再切换教师端。如果不提前说明双端关系，观众容易以为这是两个互不相关的系统。

本镜头只需要让评委提前理解三件事：

1. 软件包含学生学习端和教师决策端；
2. 学生的学习过程会被保存；
3. 教师端读取这些过程证据，完成诊断、复核和备课。

不要在这个镜头详细介绍每一个按钮。

## 3. 建议时长

18—20秒。

不建议超过22秒。

## 4. 最终完整画面布局

画面使用横向三栏结构：

```text
┌────────────────┐      ┌────────────────────┐      ┌────────────────┐
│   学生学习端    │      │   智能与数据桥梁    │      │   教师决策端    │
│                │      │                    │      │                │
│  记录生活事项   │ ───→ │  规则引擎          │ ───→ │  学生学习轨迹   │
│  完成首次判断   │      │  DeepSeek辅助      │      │  班级认知地图   │
│  专项训练订正   │ ←─── │  SQLite过程数据    │ ←─── │  教师复核备课   │
└────────────────┘      └────────────────────┘      └────────────────┘

             学生先判断  →  AI后反馈  →  教师终审
```

### 配色

- 左侧学生端：蓝色；
- 中间智能与数据桥梁：紫色；
- 右侧教师端：橙色；
- 底部原则文字：白色或深蓝色；
- 背景：浅灰白或深蓝渐变均可，但要与后续软件页面风格一致。

## 5. 动画时间轴

### 0—2秒：镜头标题出现

画面中央先显示：

```text
一个软件，两类角色，一条教学闭环
```

出现方式：普通淡入。

不要使用旋转、爆炸或粒子特效。

### 2—6秒：学生学习端出现

左侧蓝色卡片从左向右轻微滑入。

卡片内容：

```text
学生学习端

记录生活事项
完成首次判断
专项训练与订正
```

三个小项目可以每隔0.5秒依次出现。

### 6—10秒：教师决策端出现

右侧橙色卡片从右向左轻微滑入。

卡片内容：

```text
教师决策端

查看学习轨迹
形成班级诊断
完成复核与备课
```

三个小项目可以每隔0.5秒依次出现。

### 10—14秒：中间数据桥梁出现

中间紫色卡片淡入。

卡片内容：

```text
智能与数据桥梁

规则引擎
DeepSeek辅助
SQLite过程数据
```

随后出现两组箭头：

```text
学生端 → 数据桥梁 → 教师端
教师复核 → 数据桥梁 → 学生订正
```

箭头使用普通线条延伸动画即可。

### 14—20秒：教学原则出现并停留

画面底部出现：

```text
学生先判断  →  AI后反馈  →  教师终审
```

完整结构图停留4—5秒，给观众看清楚。

然后淡出并切入学生端首页。

## 6. 对应解说词

> 软件由学生学习端和教师决策端组成。学生在学习端记录生活事项，完成首次判断、专项训练和订正；规则与DeepSeek提供结构化和辅助反馈，学习过程写入本机数据库；教师在决策端查看学生轨迹和班级认知问题，完成复核与备课。下面先进入学生端，完成一条学习任务。

## 7. 解说词与画面对照

| 解说内容 | 对应画面 |
|---|---|
| “软件由学生学习端和教师决策端组成” | 左右两张角色卡出现 |
| “学生在学习端……” | 左侧学生卡三个项目出现 |
| “规则与DeepSeek……” | 中间紫色数据桥梁出现 |
| “教师在决策端……” | 右侧教师卡三个项目保持高亮 |
| “下面先进入学生端……” | 学生卡轻微高亮，随后切入学生首页 |

## 8. 交给后期人员的一句话

> 请制作一张三栏结构信息图，并让“学生端—数据桥梁—教师端”三个卡片依次淡入，最后显示“学生先判断—AI后反馈—教师终审”；这不是软件录屏，也不需要复杂动画。

## 9. 不要这样制作

- 不要把全部功能名称塞入结构图；
- 不要同时再放一条七八步的超长流程；
- 不要使用复杂三维动画；
- 不要用大量小字；
- 不要使用大红框；
- 不要把DeepSeek画成自动评分者；
- 不要写“AI最终评价”；
- 不要让信息图停留不足3秒。
