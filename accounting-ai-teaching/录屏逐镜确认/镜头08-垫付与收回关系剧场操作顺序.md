# 镜头08：垫付与收回关系剧场——实际操作顺序

## 一、开始位置

关系剧场的五步操作引导已经完成，页面回到关系剧场主界面。

如果当前案例不是“垫付与收回”，先在右侧“选择关系案例”中点击第4项：

```text
4 垫付与收回
支付人与承担人
```

## 二、三个阶段都必须分别查看两个主体

> 操作原则：每个阶段都先看“垫付学生方视角”，再看“三名室友方视角”；第三阶段为了突出谁先履行义务，也可以先看室友，再看垫付学生。下面给出固定录制顺序。

### 第1阶段：学生替室友垫付

1. 点击底部“1 学生替室友垫付”；
2. 点击右侧“垫付学生方视角”；
3. 停留2秒，查看顶部绿色关系牌：

   ```text
   垫付学生：资金－150（代付）
   ```

4. 点击右侧“三名室友方视角”；
5. 停留2秒，查看顶部橙色关系牌：

   ```text
   三名室友：取得对应消费
   ```

**【解说词】**

> 第一阶段同时观察两个主体。垫付学生作为先行支付方，资金减少一百五十元；切换到三名室友视角，可以看到室友取得了对应消费或服务。资金从垫付学生账户流出，并不意味着全部费用都由垫付学生承担。

### 第2阶段：权利与义务形成

1. 点击底部“2 权利与义务形成”；
2. 点击“垫付学生方视角”；
3. 停留2秒，查看：

   ```text
   垫付学生：收回权利＋150
   ```

4. 点击“三名室友方视角”；
5. 停留2秒，查看：

   ```text
   三名室友：归还义务＋150
   ```

**【解说词】**

> 第二阶段继续分别观察两个主体。垫付学生形成向室友收回一百五十元的权利；切换到三名室友视角，室友形成归还一百五十元的义务。同一事项从双方角度形成相互对应的权利和义务。

### 第3阶段：室友归还垫付款

这一阶段按照“履行义务的一方在先、收到归还款的一方在后”的顺序观察。

1. 点击底部“3 室友归还垫付款”；
2. 先点击“三名室友方视角”；
3. 停留2秒，查看顶部橙色关系牌：

   ```text
   三名室友：资金－150｜义务结清
   ```

4. 再点击“垫付学生方视角”；
5. 停留2秒，查看顶部绿色关系牌：

   ```text
   垫付学生：资金＋150｜权利结清
   ```

**【解说词】**

> 第三阶段先观察履行义务的三名室友：室友支付一百五十元，归还义务随之结清。再切换到垫付学生视角：学生收到一百五十元，同时原有收回权利结清。这笔资金流入是原权利的实现，不是新的收入。

## 三、完成右侧关系判断前两题

为了让普通按钮判断和后面的手势判断形成对应，先返回第二阶段：

```text
2 权利与义务形成
```

### 关系判断1/4

题目：

```text
谁拥有向室友收回150元的权利？
```

选择：

```text
垫付学生
```

停留到正确反馈出现。

**【解说词】**

> 第一题判断权利归属。收回权利属于先行支付的垫付学生。

### 关系判断2/4

系统自动进入下一题：

```text
谁承担归还垫付款的义务？
```

选择：

```text
三名室友
```

停留到正确反馈出现。

**【解说词】**

> 第二题判断义务归属。三名室友是相应费用的承担方，因此承担归还垫付款的义务。

## 四、进入手势认知闯关

**【录屏操作】**

点击页面顶部：

```text
手势认知闯关
```

打开后先停留在“四种简单手势”说明区：

```text
☝ 选择左边（选项1）
✌ 选择右边（选项2）
👍 是
✊ 否
```

**【解说词】**

> 手势不直接代表会计概念，而是作为答案提交方式：食指选择左边，胜利手势选择右边，拇指表示“是”，握拳表示“否”。摄像头视频只在本地识别，同时保留按钮备选。

## 五、手势闯关必须完整完成5题

**【录屏操作】**

> 原始录屏完整完成5题，后期成片可重点保留第2题和第3题，但不能只做两题后退出，否则成绩不会写入数据库。

### 手势题1/5：当前主体

题目要求站在垫付学生角度观察。

正确操作：

```text
☝ 选择左边（垫付学生）
```

答对后先阅读反馈；摄像头模式下将手移出画面或放下手势，待按钮变为“确认，进入下一题”后再点击。

### 手势题2/5：谁拥有收回权利

正确操作：

```text
☝ 选择左边（垫付学生）
```

答对后再次释放食指手势，再点击“确认，进入下一题”。这题建议保留在最终视频。

### 手势题3/5：谁承担归还义务

正确操作：

```text
✌ 选择右边（三名室友）
```

答对后释放手势，再点击“确认，进入下一题”。这题建议保留在最终视频。

### 手势题4/5：是否属于可收回权利

正确操作：

```text
👍 是
```

答对后释放手势，再点击“确认，进入下一题”。

### 手势题5/5：收到归还款能否直接确认收入

正确操作：

```text
✊ 否
```

阅读最后一题反馈，释放手势后点击“完成并保存”。完成后停留到出现：

```text
100分闯关完成
已保存到成长记录
```

如果摄像头识别不稳定，使用下方按钮完成相同操作。

**【五道手势题解说词】**

> 五道题依次检验当前观察主体、收回权利归属、归还义务归属、权利性质和收入边界。手势只作为答案提交方式，不替代会计判断；全部完成后，系统计算得分并将结果写入成长记录。

## 六、关闭手势闯关，返回关系剧场

1. 点击手势闯关右上角“关闭”；
2. 返回关系剧场；
3. 再选择第二阶段“权利与义务形成”；
4. 点击“垫付学生方视角”，停留1秒；
5. 点击“三名室友方视角”，停留1秒；
6. 将右侧“双主体结果”区域保持在画面中。

## 七、最后停在哪里

最终停在第二阶段“权利与义务形成”的全景：

- 左侧垫付学生；
- 右侧三名室友；
- 垫付学生的收回权利；
- 三名室友的归还义务；
- 右侧能够看到双方结果摘要。

对应结束解说：

> 通过阶段切换、主体切换、关系判断和手势闯关，同一笔垫付款被还原为“资金流出—收回权利形成—归还义务形成—权利义务结清”的完整关系链。专项训练完成后，系统将返回原事项，要求学生重新订正，而不是停留在动画或游戏得分。

## 八、进入下一镜头

点击页面右上角：

```text
保存并退出
```

系统返回原来的“记录一笔”订正区，进入镜头09。
