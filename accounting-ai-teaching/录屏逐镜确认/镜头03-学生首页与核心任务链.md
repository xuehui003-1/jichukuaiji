# 镜头03：学生首页与核心任务链

## 一、这个镜头录什么

这个镜头只录软件自带的以下三个画面：

1. 首页白色说明弹窗；
2. 操作引导第1/8步；
3. 操作引导第2/8步。

本镜头不录第3—8步，也暂时不介绍3D等式和关系剧场。它们在后面的独立镜头中再介绍。

## 二、预计成片时长

约18—22秒。

## 三、录屏前准备

1. 使用学生账号登录应用A。
2. 确认浏览器地址为：

   ```text
   http://localhost:3000
   ```

3. 确认左侧导航选中“首页”。
4. 页面滚动到最顶部。
5. 浏览器缩放设为100%。
6. 如果白色说明弹窗没有出现，可以点击页面右上角学生账号附近的“？引导”重新播放。

## 四、录屏人员逐步操作

### 画面A：白色说明弹窗

进入学生首页后，先寻找屏幕中央的白色弹窗。

弹窗顶部应显示：

```text
大学生生活记账与会计AI伴学
```

弹窗大标题应显示：

```text
先看懂一条核心任务链和按需工具
```

弹窗正文应显示：

```text
首页不是功能堆叠：记录、首次判断、诊断分流、订正变式和学习卡构成核心任务链；3D等式、关系剧场和情境库按学习困难调用。
```

弹窗右下角应有按钮：

```text
开始首页指引
```

#### 录屏操作

1. 不移动鼠标，先保持这个白色弹窗3秒。
2. 3秒后，将鼠标移动到“开始首页指引”。
3. 点击一次。

### 画面B：操作引导第1/8步

点击“开始首页指引”后，页面会出现深色遮罩和聚光灯。

请看白色引导卡右上角，必须显示：

```text
1 / 8
```

引导卡标题应显示：

```text
从“记录一笔”进入必做主线
```

引导卡正文应显示：

```text
每次学习先记录或选择一项生活经济事项；模拟事项与真实、模糊记录承担相同学习任务。
```

此时被聚光灯高亮的是首页顶部紫色大卡片，卡片中能够看到：

```text
从生活里，看见会计
记录一笔
使用模拟事项
```

#### 录屏操作

1. 保持这个画面4秒。
2. 不要点击“记录一笔”。
3. 4秒后，点击引导卡右下角的“下一步”。

### 画面C：操作引导第2/8步

点击“下一步”以后，页面会自动向下移动一点。

请看白色引导卡右上角，必须显示：

```text
2 / 8
```

引导卡标题应显示：

```text
先理解模块关系，不必从上到下全做
```

引导卡正文应显示：

```text
记录—首次判断—诊断分流—订正变式—学习卡构成核心任务链；3D等式、关系剧场和情境库按困难调用。
```

此时聚光灯高亮的是页面中的白色说明卡。

白色说明卡顶部左侧有一个小标签：

```text
先看这里
```

白色说明卡大标题是：

```text
首页不是从上到下全部必做
```

大标题下面的说明是：

```text
“记录一笔”是学习主线；其他模块根据遇到的问题按需进入。
```

白色说明卡中间有一条深蓝色横条，横条左上角写着：

```text
每次学习的必做主线
```

深蓝色横条中依次显示五项：

```text
① 记录生活事项
② 学生首次判断
③ 诊断性专项训练
④ 订正与变式
⑤ 学习卡留痕
```

这五项就是之前所说的“记录生活事项→学生首次判断→诊断性专项训练→订正与变式→学习卡留痕”。它们不是另外一个弹窗，而是在操作引导第2/8步所高亮的白色说明卡中。

#### 录屏操作

1. 确认白色引导卡显示“2/8”。
2. 确认聚光灯区域中能够看到“首页不是从上到下全部必做”。
3. 保持画面6秒，不进行点击。
4. 6秒后，点击引导卡左下角：

   ```text
   跳过本次引导
   ```

5. 页面恢复正常，本镜头录制结束。

## 五、如果找不到第2/8步

按下面顺序检查：

1. 您是否点击了第1/8步右下角的“下一步”，而不是“跳过本次引导”；
2. 白色引导卡右上角是否从“1/8”变成“2/8”；
3. 页面是否自动向下移动；
4. 当前运行的是否是最新版生产构建；
5. 如果步骤总数不是8，例如显示1/7或1/6，说明运行的是旧版；
6. 关闭旧服务器，在最新版目录重新执行构建和启动；
7. 浏览器按`Ctrl+F5`强制刷新。

## 六、本镜头对应解说词

> 现在先进入学生学习端。学生每次先从“记录一笔”开始，选择真实、模糊或模拟事项。首页并不要求从上到下完成所有模块，而是按照“记录事项、首次判断、诊断性专项训练、订正变式和学习卡留痕”组织学习；其他工具根据学生遇到的具体困难按需进入。

## 七、解说词与画面对照

| 解说词 | 软件画面 |
|---|---|
| “现在先进入学生学习端” | 白色说明弹窗 |
| “学生每次先从记录一笔开始” | 操作引导第1/8步，高亮顶部紫色卡片 |
| “首页并不要求从上到下完成所有模块” | 点击下一步，进入第2/8步 |
| “记录事项、首次判断……” | 聚光灯区域中的深蓝色五步横条 |
| “其他工具按需进入” | 第2/8步白色说明卡下方三个按需说明小卡片 |

## 八、后期人员具体处理

这个镜头的软件原生效果已经足够，后期尽量少加效果。

### 白色说明弹窗

- 不加方框；
- 不放大；
- 只保留3秒。

### 操作引导第1/8步

- 不加方框；
- 软件已有深色遮罩和发光边框；
- 在画面底部增加字幕：

  ```text
  每次学习从“记录一笔”开始
  ```

### 操作引导第2/8步

- 不加方框；
- 将聚光灯高亮区域整体放大到110%，不是115%；
- 放大持续3秒；
- 在画面底部增加字幕：

  ```text
  核心任务链：记录→判断→专项训练→订正迁移→学习卡
  ```

### 不要添加

- 不要给“记录一笔”再画蓝框；
- 不要给五步横条再画蓝框；
- 不要在本镜头用箭头指向3D等式；
- 不要在本镜头用箭头指向关系剧场；
- 不要继续播放第3—8步；
- 不要在画面上添加抽象的“主线/旁线”文字。
