# 镜头13：人机协同复核与AI备课——实际操作顺序

## 一、开始位置

教师端12/12完整引导已经结束，页面位于下方教师复核区域。

**【录屏操作】**

1. 点击页面右下角“返回顶部”；
2. 回到教师端总览；
3. 找到“教学核心亮点·AI可信评价”；
4. 点击右侧“开始亮点演示”。

**【解说词】**

> 教师端完整引导结束后，页面返回总览。教学核心亮点区域提供一段不修改正式数据的闭环演示，用于说明规则、AI、教师和学生在形成性评价中的分工。该演示不是自动播放，需要按照四个阶段逐步确认。

---

## 二、亮点演示第1阶段：发现问题

打开后，顶部流程停在：

```text
1 发现问题
```

**【录屏操作】**

1. 停留在“01·规则与AI发现问题”；
2. 展示案例标题：

   ```text
   父母转生活费，能直接认定为“收入”吗？
   ```

3. 展示左侧“学生首次判断”；
4. 展示右侧“规则＋DeepSeek”；
5. 展示AI追问和置信度；
6. 点击：

   ```text
   以教师身份进入复核 →
   ```

**【解说词】**

> 第一阶段呈现问题发现过程。学生将个人生活资金流入直接判断为企业收入；规则确认资金增加，但收入判断还取决于观察主体，DeepSeek据此提出追问。由于置信度较低，系统不直接评分，而是进入教师复核。

---

## 三、亮点演示第2阶段：教师退回

点击“以教师身份进入复核”后，顶部流程停在：

```text
2 教师退回
```

页面标题为：

```text
教师复核意见
```

**【录屏操作】**

1. 停留在教师复核意见文本框；
2. 让画面清楚显示：

   ```text
   请先明确观察主体，再判断是否适用企业收入定义。
   ```

3. 停留在两个决策位置：

   ```text
   退回学生修改
   直接通过（不建议）
   ```

4. 点击：

   ```text
   退回学生修改
   ```

**【解说词】**

> 第二阶段保留教师最终评价权。教师结合学生原始判断、规则结果和AI追问，给出专业意见；当前信息不足以直接通过，因此选择“退回学生修改”。右侧“直接通过”被弱化，提示教师优先要求学生补充理由。

---

## 四、亮点演示第3阶段：学生订正

点击“退回学生修改”后，顶部流程停在：

```text
3 学生订正
```

页面标题为：

```text
学生重新提交
```

**【录屏操作】**

1. 展示学生补充说明；
2. 展示“首次→订正”前后对照；
3. 停留2秒；
4. 点击：

   ```text
   返回教师最终确认 →
   ```

**【解说词】**

> 第三阶段由学生根据教师意见重新提交。首次判断与订正说明并列呈现，能够看出学生已从“资金流入就是收入”修正为“个人生活资金流入不能未经主体转换直接认定为企业收入”。

---

## 五、亮点演示第4阶段：最终确认

点击“返回教师最终确认”后，顶部流程停在：

```text
4 最终确认
```

页面显示：

```text
复核闭环完成
```

**【录屏操作】**

1. 展示最终结论；
2. 展示AI、教师、学生三方分工；
3. 停留3秒；
4. 点击：

   ```text
   完成演示并返回驾驶舱
   ```

**【解说词】**

> 第四阶段由教师完成最终确认。AI负责发现不确定问题，教师作出专业判断，学生完成认知订正；这不是AI自动评分，而是规则、AI和教师共同支持的形成性评价。

---

## 六、进入正式AI复核队列

亮点演示关闭后，返回教师端总览。

**【录屏操作】**

1. 点击左侧导航“AI复核”；
2. 页面滚动到“AI复核队列”；
3. 找到一条低置信度、规则冲突或重新提交记录；
4. 点击该记录右侧：

   ```text
   进入复核
   ```

5. 在“教师复核意见”中填写或保留专业意见；
6. 展示：

   ```text
   退回学生修改
   确认通过
   ```

7. 为避免改变后续录屏数据，可以只展示按钮后点击“完成并关闭”；如需要实际演示退回，则点击“退回学生修改”，等待成功提示后再关闭。

**【解说词】**

> 前面的30秒亮点演示用于说明协同逻辑，不修改正式数据。正式AI复核队列读取SQLite中的真实待复核记录，教师可以查看AI置信度、问题详情和学生补充说明，填写复核意见后选择退回修改或确认通过。

---

## 七、进入AI备课

### 第1步：进入工作台

**【录屏操作】**

点击左侧“AI备课”，页面滚动到“AI备课与资源整合工作台”。

**【解说词】**

> 教师复核解决单条记录的评价问题；AI备课进一步把班级共性认知问题转化为下一次教学设计依据。

### 第2步：选择主题和课型

**【录屏操作】**

```text
教学主题：会计主体
课型：错题讲评
```

两项同时可见时停留2秒。

**【解说词】**

> 当前案例的核心问题是个人生活视角与企业会计主体混淆，因此选择“会计主体”；为针对已经出现的错误组织反馈和再练习，课型选择“错题讲评”。

### 第3步：生成方案

**【录屏操作】**

点击“根据本班学情生成方案”，保留“正在读取学情并生成”约1秒。

**【解说词】**

> 系统读取当前班级的生活记录、数字推演、订正率和高频错误，而不是脱离班级数据生成通用教案。

### 第4步：查看依据和资源

**【录屏操作】**

先展示“班级学情摘要”，再展示“推荐内部资源”。

**【解说词】**

> 学情摘要说明方案依据；资源区域再匹配生活情境、3D等式、双主体关系和游戏工具，并标明每项资源的教学用途。

### 第5步：查看并导出方案

**【录屏操作】**

展示教学目标、情境导入、教学活动和问题链，最后停在“导出备课稿”附近。

**【解说词】**

> 系统据此形成教学目标、情境导入、教学活动和问题链，并支持导出备课稿。AI只提供可编辑草稿，是否采用和怎样调整仍由教师决定。

---

## 八、最后停在哪里

最终停在AI备课结果中的：

```text
班级学情摘要
推荐内部资源
```

二者同时可见。

结束解说：

> 至此，学生端形成的首次判断、专项训练和订正记录，已经转化为教师复核、班级诊断和教学设计依据，完成从个体学习到教师决策的闭环。
