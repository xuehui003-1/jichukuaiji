# 基础会计 AI 教学软件操作流程指引

## 一、启动与访问

### 1. 首次安装

双击：

```text
setup-first-time.cmd
```

首次安装会完成依赖安装、SQLite数据库初始化和生产版本构建。

### 2. 配置DeepSeek（在首次安装后、启动应用前）

如果需要使用真实DeepSeek AI，在首次安装成功后双击：

```text
configure-deepseek.cmd
```

在本机窗口中粘贴API Key。配置完成后再启动两个应用。

如果暂时不配置API，软件会使用离线规则模式，所有核心流程仍可运行。以后任何时候配置API都可以，但配置后必须关闭并重新启动应用服务器。

推荐首次使用顺序：

```text
setup-first-time.cmd
→ configure-deepseek.cmd（可选）
→ start-app-a.cmd / start-app-b.cmd
```

### 3. 启动应用

- 应用A：双击 `start-app-a.cmd`
- 应用B：双击 `start-app-b.cmd`
- 同时启动：双击 `start-both-apps.bat`

### 3. 本机地址

- 应用A：`http://localhost:3000`
- 应用B：`http://localhost:3001`

### 4. 局域网地址

在运行服务的笔记本上双击：

```text
show-network-address.cmd
```

其他手机或电脑使用显示的`192.168.x.x`地址访问。不要使用`0.0.0.0`。

# 三、应用A学生端操作

应用A名称：大学生生活记账与会计AI伴学软件。

## 方法一：从首页典型场景进入

1. 登录学生账号。
2. 在首页选择校园卡、花呗、垫付、退款等场景。
3. 系统自动填入模拟事项。
4. 核对参与方式、事项类别、日期、金额、支付方式和资金状态。

## 方法二：自己记录一笔

1. 点击左侧“记录一笔”。
2. 选择真实记录、模糊记录或模拟记录。
3. 选择事项与自己的关系。
4. 选择大致事项类型。
5. 填写日期、金额方式、支付方式和资金状态。
6. 用一句话描述事项，一次只写一件事。
7. 点击“通过检查并让AI整理”。

## 完成判断

1. 核对AI结构化结果。
2. 完成每一项结构化选择。
3. 在理由支架中填写观察主体、资金来源、去向、权利义务和时间节点。
4. 点击“组合为理由草稿”。
5. 用自己的语言修改理由。
6. 点击“提交首次判断”。

## 完成订正

1. 阅读规则反馈或DeepSeek追问。
2. 重新填写订正理由。
3. 点击“保存订正”。
4. 保存成功后会自动弹出“首次判断与订正对照”。
5. 以后还可以在识别结果右上角点击“查看首次与订正对照”再次打开。
6. “修改原记录”用于返回修改原始事项；“查看识别详情”用于查看AI结构化结果，这两个按钮都不是对照入口。
7. 查看对照后继续完成变式迁移。

## 查看历史

点击左侧“成长档案”，查看SQLite中保存的记录、状态和分数。

# 四、应用A教师端操作

1. 使用教师账号登录。
2. 选择教学班。
3. 查看邀请码和学习周期。
4. 在“学生账号管理”中创建试用账号，或让学生使用邀请码注册。
5. 在“学生名单与个人学习轨迹”中点击学生。
6. 查看该学生的生活记录、首次理由、订正理由和分数。
7. 点击左侧“认知地图”查看班级高频认知问题。
8. 点击“AI复核”查看低置信度和规则冲突项目。
9. 点击“成绩导出”下载CSV。

# 五、应用B学生端完整操作

应用B名称：校园数字支付与会计AI推演软件。

## 第一步：选择实验

1. 登录学生账号。
2. 在“数字支付实验场”选择一个场景。
3. 建议初次选择“校园卡充值与消费”。
4. 第一次进入会出现操作引导；以后可点击工作台顶部“操作说明”再次打开。

## 第二步：确认当前时间节点

左侧显示场景的时间步骤，例如：

```text
1. 银行卡充值校园卡100元
2. 校园卡消费15元
```

点击其中一个步骤，当前画布和判断均属于该时间节点。每个时间节点单独保存关系图。

## 第三步：建立关系箭头

在画布上方选择关系类型：

- 资金/账户
- 商品或服务
- 收回权利
- 偿还义务

操作方法：

1. 选择关系类型。
2. 可选填写金额。
3. 点击关系起点节点。
4. 再点击关系终点节点。
5. 系统生成箭头。
6. 节点可以拖动，箭头会自动跟随。
7. 点击箭头标签旁的“×”可以删除关系。
8. 点击“清空关系”可重新开始当前时点。

示例：校园卡充值

```text
关系类型：资金/账户
起点：银行卡
终点：校园卡
金额：100元
```

## 第四步：完成首次预测

在右侧选择问题答案，并填写不少于8个字的理由。理由应说明：

- 从谁的视角观察；
- 资金从哪里到哪里；
- 是否取得商品或服务；
- 是否形成权利或义务；
- 当前是什么时间节点。

## 第五步：判断会计要素

右侧会显示醒目的“会计要素判断0/5”按钮，点击后自动滚动到画布下方的“企业会计迁移”区域。

核心场景必须将以下5项全部逐项判断：

- 资产
- 负债
- 所有者权益
- 收入
- 费用

每项分别选择增加、减少、不变或不涉及。面板会显示“已判断数量/5”，未完成时提交条件区域会明确提示。

注意：这里是企业类比迁移，不把学生个人生活直接当作企业账务处理。

## 第六步：提交首次推演

右侧“本步完成状态”全部达到要求后，点击：

```text
提交首次判断
```

系统会：

- 保存首次关系图；
- 保存会计要素判断；
- 写入SQLite；
- 检查关系方向和性质；
- 调用DeepSeek或离线规则生成追问。

## 第七步：进入订正模式

1. 阅读规则反馈和AI追问。
2. 点击“进入订正模式”。
3. AI反馈区域会出现“订正说明”文本框。
4. 可以点击“返回画布修改关系”，修改箭头或会计要素。
5. 在订正说明中写明修改了什么、为什么修改。
6. 点击“保存订正结果”。
7. 如果没有修改关系、要素、理由或订正说明，系统不会允许直接完成订正。

提交后“当前推演质量”会显示关系构建、首次判断、会计要素、理由说明和订正改进五项得分，以及具体提分建议。

## 第八步：查看前后对照

保存订正后，查看：

```text
首次推演 → AI追问 → 订正推演
```

系统显示首次与订正后的关系数量、理由和关系路径。

## 第九步：切换下一时间节点

点击左侧下一步骤。已完成关系的步骤会显示“✓”。完成全部时间节点后，形成完整推演轨迹。

# 六、应用B教师端操作

1. 使用教师账号登录应用B。
2. 选择教学班。
3. 在“学生名单与个人学习轨迹”中点击学生。
4. 查看学生完成的实验、时间节点、首次选择、理由、订正和分数。
5. 点击左侧“场景热力图”查看各实验的完成率和订正率。
6. 点击“关系错误”查看最常连错的箭头。
7. 点击“时间节点”查看学生在哪个时点最容易错误。
8. 点击“AI复核”查看开放场景和低置信度内容。
9. 点击“报告导出”下载CSV。

# 七、DeepSeek配置

双击：

```text
configure-deepseek.cmd
```

在本机粘贴API Key，重启两个应用。真实AI成功时页面显示“DeepSeek真实AI”或“DeepSeek AI教练”。

需要恢复离线模式时双击：

```text
use-mock-ai.cmd
```

不要将包含真实API Key的`.env.local`发送给他人。

# 八、双设备测试建议

- 笔记本：教师账号
- 手机或台式机：学生账号

两台设备连接同一Wi-Fi。学生提交后，教师选择同一班级并刷新学生轨迹，即可看到新记录。
