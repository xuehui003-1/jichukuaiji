# 首页模块关系与使用逻辑说明

## 一、首先明确：首页不是线性课程目录

学生首页纵向排列多个模块，是为了让核心任务和辅助工具都能被快速看见，**不代表学生每次都必须从上到下完成全部模块**。

首页采用的是：

```text
一条必做主线
＋
三类按需辅助工具
＋
一个过程结果区
```

## 二、每次学习的必做主线

```text
记录或选择一项生活经济事项
→学生完成首次判断
→系统根据错误标签诊断分流
→按需完成3D等式或关系剧场专项训练
→返回原任务完成订正
→变式迁移
→最近学习卡和成长档案留痕
```

入口是首页顶部的：

```text
记录一笔
使用模拟事项
```

“记录一笔”不是普通记账，而是生成一次完整的会计认知任务。

## 三、三个按需分流入口

### 1. 不知道练什么

进入：

```text
本阶段练习推荐
校园经济生活图谱
全部生活情境
```

用途：帮助学生选择合适的生活事项。

- 本阶段练习推荐：给出当前优先巩固任务；
- 校园经济生活图谱：按照钱的来源、去向、往来和交易反转分类；
- 全部生活情境：直接选择具体案例。

选择后仍然回到“记录—判断—追问—订正”的主线，不是另一套孤立流程。

### 2. 会计等式和要素增减不清

进入：

```text
3D会计等式平衡实验室
```

适用情况：

- 只会机械回答“平衡”；
- 不会指出具体账户增减；
- 混淆资产、负债和所有者权益；
- 需要练习教材九类经济业务。

它是专项补救工具，不是每次记录前必须完成的步骤。

### 3. 主体、债权债务和权利义务不清

进入：

```text
生活经济关系剧场
```

适用情况：

- 不知道站在谁的角度判断；
- 把收到的钱都当作收入；
- 把付出去的钱都当作费用；
- 忽略押金返还权、垫付收回权和偿还义务；
- 需要比较同一事项的双方结果。

它同样是专项补救和迁移工具。

## 四、页面纵向位置的设计依据

### 第一层：顶部主任务

```text
从生活里，看见会计
记录一笔 / 使用模拟事项
```

放在最上方，因为它是学生最主要、最高频的入口。

### 第二层：主线与分流说明

```text
首页不是从上到下全部必做
```

紧接主任务，用于告诉学生模块之间的关系。

### 第三层：两个核心认知模型

```text
3D会计等式
生活经济关系剧场
```

放在靠上位置，是因为它们分别对应基础会计的两个核心难点：

- 要素与等式；
- 主体与权利义务。

同时也是竞赛展示中最具辨识度的两个自主开发工具。

### 第四层：任务选择与情境库

```text
本阶段练习推荐
校园经济生活图谱
全部生活情境
```

用于学生不知道记录什么，或需要按知识问题选题时进行分流。

### 第五层：数据反馈

```text
本周期有效记录
待订正
变式迁移
最近学习卡
```

放在页面下部，因为它们是完成学习任务后的结果反馈区，而不是开始操作的入口。

## 五、课堂使用方式

### 方式A：教师统一布置

```text
教师指定“垫付与收回”
→学生直接进入对应情境
→完成主线
→教师查看班级错误
```

### 方式B：学生自主选择

```text
学生查看学情推荐或生活图谱
→选择自己需要的情境
→完成主线
```

### 方式C：针对性补救

```text
教师发现等式错误
→安排3D等式实验

教师发现主体/债权债务错误
→安排关系剧场
```

### 方式D：课后拓展

```text
完成记录主线
→进入3D等式或关系剧场
→完成专项迁移
```

## 六、演示视频推荐解说词

> 首页并不是要求学生从上到下完成所有模块，而是采用“一条主线、按需分流”的结构。每次学习的必做主线是：记录或选择一项生活事项，完成首次判断，在规则和AI追问后进行订正，并把过程保存为学习卡。当学生不知道练什么时，可以使用学情推荐、生活图谱或情境库；当学生混淆会计要素和等式时，进入3D等式实验；当学生混淆会计主体、债权债务和收入费用时，进入生活经济关系剧场。页面下方则集中展示本周期记录、待订正、变式迁移和最近学习卡。

## 七、设计说明书推荐表述

> 学生首页采用“核心任务＋诊断分流＋专项工具＋过程反馈”结构。核心任务是生活事项的首次判断、智能追问和学生订正；学情推荐、生活图谱和情境库负责选择学习材料；3D会计等式实验和双主体关系剧场分别服务于要素等式、主体权利义务两个核心难点；学习卡和成长档案负责沉淀过程证据。各模块不是简单堆叠，也不是必须依次完成，而是围绕同一学习主线按学情调用。
